# Procreate Basics - Курс рисования

Главная страница курса "Основы Procreate" от Евгении Гагариной.

## Стек технологий

- **HTML5** - структура
- **CSS3** - стилизация с использованием CSS переменных
- **JavaScript (Vanilla)** - интерактивность
- **shadcn/ui** - компоненты (кнопки, карточки)

## Функции

✨ Современный дизайн в стилистике Procreate
📱 Полностью адаптивный (Responsive)
🎯 Оптимизирован для SEO
⚡ Высокая производительность
🎨 Красивые анимации и переходы

## Структура проекта

```
.
├── index.html      # Главная страница
├── styles.css      # Стили
├── script.js       # Скрипты
└── README.md       # Этот файл
```

## Запуск

1. Откройте `index.html` в браузере
2. Или используйте Live Server (VS Code расширение)

## Секции

- **Navigation** - навигационное меню
- **Hero** - главный баннер
- **Features** - что вы изучите (6 карточек)
- **Course Details** - информация о курсе
- **Author** - информация об авторе
- **CTA** - призыв к действию
- **Footer** - подвал
